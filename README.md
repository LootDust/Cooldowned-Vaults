# Cooldowned Vaults

## How to use

Download release jar and install like other fabric mods, enjoy reusable vaults.

## How to change the cooldown

Rewrite [the numbers at line 128](src/main/java/com/lootdust/cooldownedvaults/mixin/VaultBlockEntityMixin.java) here and compile whole project at your own.
